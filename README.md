# Local Business Schema Generator

Live tool: https://digitaldawnin.github.io/local-business-schema-generator/

A free, browser-based tool for generating JSON-LD structured data for local businesses.

## Features

- Generate `LocalBusiness` and related schema types
- Business name, website, phone, email and description
- Address information
- Latitude and longitude
- Opening hours
- Price range
- Logo and image URLs
- Social profile links
- Live JSON-LD preview
- Copy generated JSON-LD
- Download generated JSON
- Works entirely in the browser
- No backend, API keys or database required

## How to use

1. Enter accurate information about the business.
2. Choose the most appropriate business type.
3. Add address and opening hours where applicable.
4. Click **Generate Schema**.
5. Copy the JSON-LD.
6. Add it to the relevant page of the business website inside a `<script type="application/ld+json">` block.
7. Validate the implementation with current structured-data documentation and validation tools.

## Important notes

Use accurate business information. This tool generates JSON-LD but does not guarantee rich results, enhanced search features, or improved rankings.

The application generates the schema locally in the browser. Form data is not sent to a server by this project.
