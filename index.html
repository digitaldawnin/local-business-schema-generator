How to use it

  1. Enter accurate information about the business.
  2. Choose the most appropriate business type.
  3. Click Generate Schema.
  4. Copy the JSON-LD code.
  5. Place it in a JSON-LD script block on the relevant page of the website.
  6. Validate the implementation with current structured-data documentation and validation tools.

This tool runs entirely in your browser. No business details are uploaded to a server by this application.
